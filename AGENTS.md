# Contributor instructions

This repository contains an offline Node.js tool and original WordPress/Elementor workflow documentation.

- Preserve offline, read-only inspection. Do not introduce telemetry or API calls.
- Never copy client repositories, credentials, uploads, exports, or paid plugin source into this project.
- Keep normal page content editable through native Elementor elements.
- Do not claim an editor action, import, test, deployment, or adoption signal without evidence.
- Use node --test and npm run check:example for inspector changes.
- Add meaningful regression coverage when behavior changes.
- Keep docs and CLI exit codes synchronized.
- Record exact software versions for live compatibility claims.
- Keep scope small and update CHANGELOG.md for user-facing changes.
