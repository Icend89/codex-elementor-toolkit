# Build a native Elementor page

Inputs: target test site/page, original brief/copy, approved assets, exact versions, permitted changes, required viewports.

Read docs/elementor-workflow.md. Inspect available editor access. Map page regions to native Container, Heading, Text Editor, Button, and Image elements. Keep ordinary content independently editable. Use editor controls for visual styling.

If editor access exists, build only on the named draft page and verify each material change. Otherwise produce a construction recipe and clearly state that no page was created. Do not fabricate tool access or use raw database writes as a shortcut.

Deliver the element map, changed page identifier when actually available, local export inspection if performed, and the results of save/reopen, responsive, keyboard, and link checks. List unresolved checks and any bounded custom-code exception with its reason.
