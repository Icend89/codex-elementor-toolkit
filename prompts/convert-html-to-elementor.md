# Rebuild an HTML design in Elementor

Inputs: authorized source HTML/design, target draft page, editable-field requirements, versions, assets with redistribution status.

Read docs/html-to-elementor.md. Inventory content and interactions. Produce a source-to-native-element mapping. Rebuild ordinary content with native widgets and layout controls. Do not place the full page in one HTML widget.

Keep unsupported interactions in a separate, scoped implementation proposal. Do not invent CPT fields, Dynamic Tags, Pro features, or external plugins. Confirm the content model before using dynamic collections.

Deliver the mapping, work actually performed, comparison at matching viewport sizes, save/reopen evidence, and remaining differences. Keep client source and exports private; create a separate original reproduction for any public contribution.
