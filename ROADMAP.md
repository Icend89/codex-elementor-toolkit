# Roadmap

These are planned outcomes, not completed features or promised dates.

## Next: real compatibility evidence

- Test the original sample on a clean WordPress/Elementor installation.
- Record versions, import steps, editing, save/reopen, and responsive results.
- Fix and regression-test any issues found during that test.

## Next: usability from real feedback

- Invite developers to try one concrete workflow and report friction.
- Add original reproductions for actual export variations.
- Improve finding messages where users cannot identify a repair.
- Consider a comparison command only after a demonstrated review need.

## Later, subject to evidence

- Document one reproducible Theme Builder / CPT workflow with a proper test site.
- Evaluate supported integration points for automation; avoid undocumented editor APIs.
- Grow the version matrix as actual tested environments become available.

No star targets, simulated contributors, artificial issue churn, or release-count goals. A useful fix is a better maintenance signal than empty activity.
